# Tugas-Besar-Kelompok_I_Ojek-online-Anter.in-
Aplikasi ojek online Anter.in mencatat data driver dan penumpang yang menggunakan layanan. Seorang driver melayani banyak penumpang dan sebaliknya sesuai pesanan harian. Keduanya dapat melihat riwayat perjalanan. Relasi layanan driver dan penumpang dikelola dengan Multi Linked List, sedangkan pesanan perjalanan disimpan di dalam Binary Search Tree.
